# mdmorais25-bot.github.io

Site raiz do GitHub Pages. Guarda o `.well-known/assetlinks.json`, que liga o APK do app Treino na Sala (`io.github.mdmorais25bot.treinonasala`) ao site https://mdmorais25-bot.github.io/treino-na-sala/ para ele abrir em tela cheia. O `.nojekyll` é necessário para a pasta `.well-known` ser publicada.
